# Industrial Training Kits — Phase 4

An interactive web application built with a dynamic UI, accessible modals, custom theme toggle, and a complete form validation engine.

## Features
- **Registration Gate:** Full Name, Email, and Password validation using Regex.
- **Accessibility:** Screen reader friendly with `aria-live` and `aria-invalid` state handling.
- **Dynamic Payload:** Real-time JSON payload generation on successful submission.
- **Interactive UI:** Dark/Light mode, live search, and technical spec modals.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla ES6)
